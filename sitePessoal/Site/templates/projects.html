Personal Webpage

         

My most recent project is this personal webpage you're currently viewing.
It's built with Django and serves as a portfolio to showcase my skills and projects. The design is primarily based on the Bentolio template from Figma, which you can check out here.

Although still under development, the technologies used so far include: Django as the core framework, Django Channels to handle real-time features like the contact-me chat, JavaScript to manage interactivity in the chat, Redis as a message broker, HTML and CSS for the structure and styling.

This project has been a great learning experience — it gave me many new insights and helped deepen my understanding of Django and web development.

Next steps: I plan to implement a blog post system to make content publishing easier.

Meme Bot for discord

 

While working on a project, I felt like our Discord server was missing something — it was almost empty and too boring.

So, I decided to make a bot that would display something — news, or even weather, if it was interesting. While looking for free APIs to use, I came across one that retrieves the most liked photos from a programming subreddit.

I used Python to consume the API, using async for the first time. The most difficult part was understanding how to configure it for Discord, but after just two hours, the bot was up and already sending good memes.

It was a really nice and quick project. I got the chance to learn how to use async, consume APIs, and create good logs. It was also my first time deploying something on a platform like Discord — in this case, a bot. Once you understand the basics, it's actually pretty fun, and you definitely need to try it!
